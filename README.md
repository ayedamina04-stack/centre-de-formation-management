# Training Center Management System

A web-based application developed to simplify and manage the daily activities of a training center.

This project was built as part of an academic project using PHP, MySQL, HTML, CSS, and JavaScript.

The application provides different interfaces for administrators, trainers, and participants, allowing each user to access the functionalities related to their role.



## Features

### Administrator
- Manage trainers.
- Manage training courses.
- Manage classrooms.
- Manage training sessions.
- Activate and deactivate user accounts.

### Trainer
- Access a dedicated trainer interface.
- Consult assigned training sessions.
- Manage training-related information.

### Participant
- Create an account and log in.
- Browse available training courses.
- Consult training sessions.
- Access the participant interface.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
